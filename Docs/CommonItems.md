# 常用物品监控

位于“玩家技能冷却监控”下方。支持启动模块、缩放、无目标时隐藏、排列方向、预览和解锁移动。初始排列为居中，初始移动区域中心为 `(0, -240)`，图标基准尺寸与玩家技能监控一致。

## 两类设置

- **通用物品设置**：同一客户端内，账号下所有角色共用。
- **职业物品设置**：按职业保存，同职业角色共享。

两组各有初始空行，可以独立添加、删除和拖拽排序。游戏中先显示通用列表，再显示当前职业列表。物品分类填写名称或 ID 后生成图标；装备分类按所选部位生成图标。已配置的图标保留，不因物品数量为零而隐藏，便于右键制造尚未持有的物品。

每条先通过“监控分类”选择“物品”或“装备”。

选择“物品”时，左侧填写物品名称或 ID，右侧可填写制造该物品的技能名称，也支持技能 ID。名称解析依赖客户端可获取的物品资料；未缓存的名称可改用物品 ID。输入框前显示物品图标，未输入或无法识别时使用红色问号。制造输入框为空时，显示“在此输入制造技能名。”；鼠标提示为“如果左侧是制造物，可在此输入制造技能名以便右键制造”。

选择“装备”时，右侧显示装备部位下拉菜单。下方只保留一个只读名称框，自动显示该部位当前装备名称和图标；不显示制造技能输入框，也不绑定右键制造。换装后自动跟随部位，空部位显示“未装备”和红色问号。旧版无分类条目按“物品”处理，原输入内容保留。

## 点击与冷却

- **左键**：使用已配置物品。“装备”分类固定绑定所选装备位置编号，随换装更新对应物品；未装备时不会穿上背包中的装备。“物品”分类中的装备名称／ID 仍仅在已装备时允许使用，不执行自动穿戴。
- **右键**：施放用户填写的制造技能。未填写时没有右键制造动作。不从物品的使用效果技能猜测制造技能，也不自动制造物品。
- **冷却**：读取物品／装备公开冷却，包括游戏返回的共享冷却。冷却中图标褪色并使用 50% 透明度，上方显示倒计时；文字保持不透明。沿用秒数与 `分:秒` 的格式。
- **数量**：普通物品图标下方显示背包内所有堆叠的合计数量，不计银行库存，也不显示装备数量。数量至少为 2 时才显示数字，0 和 1 均隐藏数字。数量为零时图标褪色并使用 50% 透明度，仍保留右键制造。数量和倒计时字号相同；数量文字在图标底部内侧，横向右移 2 像素。数量和倒计时文字保持不透明；获得物品后，若未在冷却中则恢复彩色。

使用与制造遵守物品、技能本身的目标、材料、等级、职业和战斗限制。例如使用需要选取武器的强化物品时，仍保留游戏原有选取流程。

## 战斗与配置

游戏内按钮使用安全动作模板，左键绑定物品或装备位置，右键绑定制造技能。可在战斗中点击已配置按钮。安全按钮树独立放置在 UIParent 下，不作为渲染器或头像锚点的子节点，避免保护状态传播到设置预览和其他模块。

战斗中只刷新图标和冷却表现，不改变按钮布局、动作属性或可见性驱动。装备分类的部位编号不变，可以在战斗换装后直接更新名称、图标和冷却；右键保持无动作。物品信息、背包或装备变化导致的重新绑定延后至脱战；设置面板沿用现有战斗编辑限制。需要依目标显示时，通过游戏安全状态驱动处理。

“其他”中的全局配置分享包含本模块的通用列表、全部职业列表及布局设置。导入内容仅按数据验证，不执行输入框中的脚本或宏文本。
