# 监控输入框的法术名称显示

输入可识别的 Spell ID 后，确认输入或离开输入框时显示客户端提供的法术名称。已有配置中的 ID 在打开对应设置时也以名称显示，无法识别时保留原始 ID。

名称只用于界面显示。保存、监控匹配和配置分享继续保留输入的准确 ID，避免同名不同等级、不同效果的法术混淆。直接输入名称仍按名称保存，清空输入和取消编辑保持原有行为。

适用于职业技能监控、装备触发与其他监控的法术输入和补充表的 Buff Spell ID、获取队友 Buff 监控、团队易伤监控和团队 Buff 缺失监控的两个法术输入，以及常用物品的制造技能和宠物 Buff 输入。冷却黑名单中的可识别法术 ID 也以名称显示，黑名单匹配数据保留 ID。物品 ID、装备 ID、声音 ID 和快捷键文字不作为法术转换。
