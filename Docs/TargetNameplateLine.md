# 头像到目标姓名板连线

从 MangUI 主头像区域中心连接至当前目标姓名板中心，白色直线，厚度 2，透明度 75%。默认开启，在“其他 → 显示 → 头像到目标姓名板连线”切换，随全局配置分享保存。

起点使用独立的主头像区域锚点，不依赖会隐藏的目标头像图层。仅在双方界面坐标可读取时，按各自有效缩放换算到同一全屏图层绘制。不提供游戏场景中的人物模型或地面定位。

时光服实际验证同时拒绝 `NamePlate:GetCenter()`（Can't measure restricted regions）和跨区域 `Line:SetEndPoint()`（Not allowed to depend on NamePlate）。这些限制下无法实现本功能。检测后停止对该姓名板重复测量，禁用设置中的开关并显示客户端不支持提示；不再尝试受禁止的姓名板原生锚点。自动测试不代表受限客户端内实际可绘制。

无目标、目标姓名板不可见、头像隐藏、界面隐藏或接口限制访问时隐藏；更换目标、重新显示姓名板后恢复。线条不接收鼠标操作，不移动或修改头像及姓名板。设置预览及解锁移动预览不额外生成连线。
