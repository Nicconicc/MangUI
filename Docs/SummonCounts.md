# 玩家技能监控：召唤物数量

技能冷却监控的层数位置统一采用以下优先级：

1. 已登记的限时召唤技能：显示玩家当前在场的召唤物数量；0 时隐藏，1 时也显示。雄鹰显示 1 或 2。
2. 其他技能：沿用技能充能次数。

召唤数量和技能冷却分别处理。上方原有倒计时仍表示技能冷却；数量与倒计时共用 16 号字体大小，数量文字保持完整透明度。目标 Debuff 的层数规则保持不变。

## 已接入

- 时光服，接口 38001 / 38002。
- 雄鹰射击：施法 ID 1284199，玩家身上的召唤计数 Buff ID 1284379。
- 支持输入技能 ID 或由客户端解析出的本地化技能名称。
- 数量直接读取玩家的计数 Buff。每只雄鹰的到期、替换和提前移除交由游戏维护，不通过再次施法延长全部雄鹰的寿命。
- 不依赖本地施法历史，切换目标不会清空数量，重新加载后可以恢复游戏仍提供的数量。

## 扩展规则

`Code/Modules/Cooldowns/PlayerSkills.lua` 中的 `summonCountRules` 登记客户端、技能及其权威计数来源。目前只登记已验证的时光服雄鹰射击。未来同类技能也使用当前在场数量覆盖充能数字，并须按具体版本核实计数来源；不能用单个技能冷却推算全部召唤物的剩余数量。

无限服的“召唤雄鹰”是另外的技能，未核实它的计数来源前不复用时光服的 Buff ID。
