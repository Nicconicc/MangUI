# 模块辅助线

以下模块共用辅助线绘制和控制面板，每个模块独立保存设置：

| 模块 | 默认文字 |
| --- | --- |
| 宠物框体 | Pet frame |
| 目标的目标框体 | Target of target frame |
| 焦点框体 | Focus frame |
| 队伍框体 | Party frames |
| 获取队友Buff监控 | Teammate buff |
| 团队易伤监控 | Raid vulnerability |
| 团队Buff缺失监控 | Missing raid buff |
| 仇恨监控 | Threat |
| 鼠标光圈提示 | Mouse highlight |

各模块控制面板最下方显示黄色“辅助线”分段标题。控件采用统一间距，百分比调节与文字输入框等宽并对齐：

- **显示辅助线**：仅鼠标光圈提示默认勾选，其他模块默认不勾选。勾选显示斜线、平线和圆点；文字独立控制，所有模块默认勾选“显示文字”。
- **辅助线透明度**: 0%–100%, 默认60%。
- 文字默认12号，可独立调节，模块缩放时保持屏幕尺寸不变。
- **辅助斜线长度**：0%～100%，默认100%。100%连接到主头像外框边缘，0%收回模块旁的拐点，圆点随斜线端点移动。
- **辅助平线长度**：0%～100%，默认100%。100%保持标准横线长度，减小时拐点向模块靠近，0%时横线收起。两个长度调节互相独立。
- **显示文字**：默认勾选；右侧输入框可编辑。默认取对应页签英文名并删除 `tracking`，自定义文字不随界面语言翻译。回车或离开输入框保存，Esc取消当前输入。

辅助线为白色、透明度由各模块的“辅助线透明度”独立调节，默认60%，线段和端点圆点绘制在界面背景层，不遮挡其他界面；文字保持原有显示层级和所选屏幕字号。文字位置随模块调整，字号不随模块缩放。平线宽2个屏幕像素；斜线使用柔边纹理，主体宽2个屏幕像素，两侧各有1像素透明度渐变。圆点直径8个屏幕像素。模块缩放、主头像移动和模块拖动时实时更新。

头像类模块按可见外观框体范围连接；队伍框体使用整个可见队伍区域的一根辅助线。Buff监控按模块提供的图标行布局适配，布局为空时隐藏；原生受限光环沿用原模块的监控位规则，不额外读取受保护的存在状态。仇恨辅助线跟随仇恨文字的显示条件；鼠标光圈只保留辅助斜线，控制面板不显示“辅助平线长度”。斜线沿光圈中心与主头像中心的连线，动态连接两个圆形外观的边缘，随鼠标方向、光圈大小及缩放实时适配；100%连接头像边缘，0%收回光圈边缘，保留头像方向端点的圆点。已保存的平线长度不影响鼠标光圈。两个外观重叠时隐藏连接线与圆点。模块或单位隐藏时辅助线和附属文字一起隐藏。所有装饰均不响应鼠标，不改变单位点击菜单。

单模块设置预览没有可见主头像时，只展示模块及附属文字，不连接到预览之外的游戏头像。预览范围包含文字，完整解锁预览则可展示各模块间的连接。

旧配置补入各模块默认值，保留团队Buff模块已保存的个性化设置。所有辅助线设置随布局保存、重载、模块重置及整体配置分享保留。读取的几何对象仅限本插件普通外观框体，不读取原生光环框、单位血量或冷却的受限数据。


## 辅助线文字字体

所有十三个辅助线模块可独立选择字体和字号（4–150，默认12）。字号不随模块缩放。黑色阴影偏移为(2, -2)，同样不随模块缩放。设置随布局保存、重载和整体分享保留。

## 新增监控模块

| 模块 | 默认文字 |
| --- | --- |
| 职业技能监控 | Class skill |
| 装备触发与其他监控 | Equipment procs and other |
| 冷却监控 | Cooldown |
| 常用物品监控 | Common item |

新增模块共用完整辅助线设置，按实际图标行数量和排列方向适配，图标行为空时隐藏辅助线和文字。冷却监控使用居中图标行的实际宽度。常用物品沿用“无目标隐藏”条件，不读取安全按钮的几何或可见状态。

辅助线文字使用与角色名一致的黑色描边和实心黑色文字阴影，偏移仍为(2, -2)，而非原生淡色字体阴影。
