# 头像到目标姓名板连线

从 MangUI 主头像区域中心连接至当前目标姓名板中心，白色直线，厚度 2，透明度 75%。默认开启，在“其他 → 显示 → 头像到目标姓名板连线”切换，随全局配置分享保存。

当前为姓名板子框体验证版：在目标姓名板下创建线段宿主，线的一端锚到宿主中心，另一端反向锚到独立的主头像区域。不读取姓名板位置、尺寸、缩放，也不把界面根层的线段锚到姓名板。不提供游戏场景中的人物模型或地面定位。

已实测失败的是读取姓名板坐标，以及把根界面层的线段锚到姓名板；这不等价于已经验证反向挂载也失败。当前验证线段先属于姓名板布局范围后，能否把另一端锚到头像。该端点若也被拒绝，则记录原始错误，停止重试并提示不支持。自动测试不代表客户端中实际可绘制，需要实机验证。

无目标、目标姓名板不可见、头像隐藏、界面隐藏或接口限制访问时隐藏；更换目标、重新显示姓名板后恢复。线条不接收鼠标操作，不移动或修改头像及姓名板。设置预览及解锁移动预览不额外生成连线。
