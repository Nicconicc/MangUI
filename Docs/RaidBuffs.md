# 玩家常驻团队增益监控

位于“常用物品监控”上方，监控玩家自身缺少或即将到期的团队增益。缺少 Buff 时显示图标；剩余时间小于 3 分钟时也显示，并在图标上显示倒计时。剩余时间至少 3 分钟或永久增益隐藏。来源可以是自己、队友或其他玩家。

支持启动模块、缩放、无目标时隐藏、排列方向、预览和解锁移动。图标基准尺寸 40×40，默认排列居中，默认移动区域中心为 `(0, -400)`。

图标行下方显示可编辑文字，默认取“团队Buff缺失监控”页签的英文名并去掉 `tracking`，即 `Missing raid buff`。文字直接按输入显示，不随界面语言翻译。字体为 19.2 号，文字中心在图标行中心下方 50 个布局单位。之前的白色矩形边框、图标右侧短线及文字两侧横线全部删除，不再创建这些装饰纹理。

控制面板最下方以黄色“辅助线”分段标题提供以下设置。各项按等间距单行排列，两个百分比控件与文字输入框等宽、共用右侧一列，标签与控件垂直居中：

此面板也用于宠物、目标的目标、焦点、队伍、获取队友Buff、团队易伤、仇恨和鼠标光圈模块。各模块独立保存；默认文字和显示行为见 [模块辅助线](ModuleGuides.md)。

- **隐藏辅助线**：默认不勾选；勾选后隐藏斜线、短横线和端点圆点，文字独立控制。
- **辅助斜线长度**：默认 100%，按 1% 调节，范围 0%～100%。100% 时斜线连接到主头像外框边缘，0% 时斜线收回拐点，只保留短横线和位于拐点的圆点；中间值在两端之间连续插值。圆点始终跟随斜线靠头像的一端。
- **辅助平线长度**：默认 100%，按 1% 调节，范围 0%～100%。100% 为原来的拐点到模块横线长度；减小时拐点向模块移动，0% 时横线收起、拐点到达模块边缘。斜线随新拐点重新连接，斜线百分比保持独立。旧配置自动补入 100%，保留现有横线长度。
- **显示文字**：默认勾选，右侧输入框可编辑内容；回车或离开输入框保存，Esc 取消当前输入。文字与辅助线可分别显示、隐藏。

辅助线为白色、60% 不透明度。短横线为两个屏幕像素；斜线使用独立柔边纹理与线性采样，中央实色部分为两个屏幕像素，两侧各有一个屏幕像素的透明渐变过渡，以减轻斜向锯齿。圆点直径为 8 个屏幕像素、不透明度为 60%。分辨率或模块缩放变化时保持上述屏幕像素尺寸。图标数量、排列方向、头像和监控位置变化时辅助线实时适配；移到头像另一侧时自动镜像。

这些显示设置随布局保存、重载及整体配置分享保留。头像、监控隐藏或图标行为空时辅助线隐藏；独立监控预览没有主头像时不绘制辅助线。只读取本插件普通外观框体的位置，不锚定外部安全头像框或原生光环框，也不增加鼠标响应区域。原生受限光环客户端仍沿用下文所述的监控位布局，不额外读取受保护的光环状态。

“仅团队时显示”在“无目标时隐藏”右侧，默认勾选，按加入团队判断，并不要求已经进入团队副本。取消勾选后可在其他场景显示；与“无目标时隐藏”同时启用时，两项条件都需满足。设置面板预览不受这两项条件限制。

## 配置分组

- **通用Buff设置**：同一客户端内账号角色共用的完整列表，不再单独显示“职业Buff设置”。
- 每条设置下方的“职业加载”提供职业颜色菱形开关，使用左侧标签相同的图标，先去除贴图底色再染成职业颜色。关闭时褪色且透明度为 50%，悬浮显示职业名称。只显示当前客户端版本已开放的职业：经典／TBC／无限服 9 个、时光服 10 个、MoP 11 个、正式服 13 个；不删除其他职业已保存的开关。区块高度缩短，类型标题上方与职业加载行下方各留 10 个布局单位。
- 所有职业都能查看、编辑、排序全部设置。预览和游戏内图标只加载勾选了当前职业的条目。新建条目默认勾选全部职业；全部关闭时仍保留设置行，不生成监控图标。
- 旧通用条目自动启用全部职业，旧职业条目合并到此列表并只启用原职业；相同条目合并职业开关。首次迁移保留旧数据备份，重新登录不会重复合并。

列表默认一个空行，支持添加、删除和拖拽排序。每条监控提供“常驻Buff”“职业武器强化”“消耗品武器强化”类型。旧配置自动按“常驻Buff”处理，不改变已有内容。

常驻 Buff 包含图标、两个横向 Buff 名称或 ID 输入框，以及删除按钮；两输入框中间标注“或”，只要任意一个 Buff 剩余至少 3 分钟或为永久增益，该条图标就隐藏。两者都不存在时显示一个图标；仍有增益但都不足 3 分钟时，显示较长的剩余时间。允许只填写其中一个输入框，两个都为空时不生成监控图标。旧配置保留为左侧输入，右侧为空。占位文字为“输入Buff名称或ID”。名称按当前客户端识别，ID 按对应 Buff 的法术 ID 匹配。默认显示左侧 Buff 图标；左侧未填写或无法解析图标时使用右侧图标，均无法解析时显示问号。

名称识别独立于当前职业法术书：常用团队增益通过客户端法术数据建立跨职业索引；实际获得过的 Buff 名称、图标及同名等级 ID 会按客户端版本和语言缓存。其他未识别的名称在此设置页打开且脱战时分帧查找，找到后自动更新图标；可直接填写 ID。按名称或 ID 监控常驻 Buff 均兼容同名不同等级；输入的原始 ID 仍保存在配置中。

提醒图标正常彩色、完全不透明，不提供物品使用或制造点击动作。完全缺失时不显示倒计时；即将到期时使用 `2:59`、`1:20` 格式，不足一分钟显示秒数。不显示堆叠数。普通客户端会将提醒项目紧凑排列；使用原生受限光环接口的客户端将两输入的 Buff ID 集合交给游戏判断，由游戏控制图标隐藏与倒计时，保留各监控位置以避免比较受保护的光环状态。时间跨过三分钟阈值无需重新触发增益事件。

“其他”中的全局配置分享包含本模块的完整列表、每条职业开关和显示设置，并兼容导入旧版通用／职业列表。旧配置缺少本模块时自动补入默认值。新增模块不改动物品监控数据。

## 武器强化缺失提醒

- **职业武器强化**：盗贼、萨满、术士、圣骑士可选择自动推荐或指定强化。设置列表提供当前版本支持的各职业强化，以便在同一角色上配置其他职业；实际提醒仍要求当前角色已学会、适用于武器且符合版本限制。不包含死亡骑士符文熔铸。经典盗贼分别检查武器，MoP 及之后的毒药按玩家自身增益检查。探索赛季自动规则兼容致命酝酿。术士涂层仅在 WLK 与无限服启用；TBC 装备型石头不会错误提醒。
- **消耗品武器强化**：输入物品名称、物品 ID、物品链接，或将背包物品拖入输入框／图标。也可输入部分名称后点击“选择”，在当前版本的物品列表中筛选。识别后显示物品图标和名称。未收录的物品提示“暂不支持此物品，请从列表选择”，不会生成错误提醒。列表内同一产品的各品质均视为满足该产品。
- **检查位置**：主手、副手、主副手、任一武器。主副手分别生成缺失图标；任一武器只要求一把适用武器满足。未装备武器、盾牌、非武器副手、未学会的职业强化和等级不足的物品不会生成提醒。磨刀石、平衡石及远程强化还检查武器类型。
- **显示**：缺失时显示图标，剩余时间小于 3 分钟时显示图标及倒计时，补充至至少 3 分钟后隐藏；战斗中、脱战、换装备及强化过期后都会刷新。“任一武器”以符合强化的武器中最长剩余时间判断。共用模块缩放、方向、团队与目标显示条件、预览和解锁移动。图标标注主手／副手，英文为 MH／OH，悬浮显示物品或技能详情及缺失或即将到期的位置，不提供自动使用或施法。
- **识别**：优先读取临时武器强化的具体附魔 ID，兼容旧接口与 `C_PaperDollInfo.GetTemporaryEnchantmentInfo`。不使用触发后的短时增益，也不读取物品链接中的永久附魔 ID。对自定义客户端不同 ID 或叠加效果，补充检查武器详情中的对应强化名称；不可读取的受保护状态不推断为缺失。时光服不套用原版 WLK 的旧物品等级限制。

录入示例：选择“消耗品武器强化”，输入 `34539`（正义武器涂层），检查位置选择“主手”，再选择需要启用的职业。数据随完整列表及职业开关保存和分享，无需用户查找附魔 ID。

时光服“尤亚姆巴巫师之油”（物品 `267773`）实际赋予玩家 Buff `1282985`，不属于消耗品武器强化。应选择“常驻Buff”并填写 `1282985`，监控玩家自身增益；仍遵循缺失及剩余不足三分钟的提醒规则。旧版本已保存的该物品监控（名称、物品 ID 或链接）自动转换为上述 Buff，包含通用列表、各职业列表及导入配置，不再检查武器位置。

## 模块配置分享

设置面板底部的黄色“配置分享”分段提供“导出全职业配置”“导出当前职业配置”“导入配置”。按钮悬浮时文字变黄。全职业配置包含完整列表和各职业开关；当前职业配置只包含该职业已启用的条目。单职业导入仅更新对应职业的设置，保留其他职业的启用内容；全职业导入替换完整列表。兼容旧版模块分享字符串，旧版单职业导入保留原通用条目。各模块字符串独立校验，不能导入到其他模块。“其他”中的整体配置分享继续包含全部列表、职业开关与布局。

常驻 Buff 输入为某等级 ID 时，按该 ID 解析出的名称匹配已知同名等级。两个输入任意一个存在且剩余至少三分钟（或永久）即可隐藏提醒；多等级同时存在时采用最长有效持续时间。该兼容仅用于玩家 Buff 缺失判断，其他监控的精确 ID 规则不变。
