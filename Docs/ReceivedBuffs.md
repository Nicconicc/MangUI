# 玩家获取他人增益监控

位于“玩家技能冷却监控”下方。玩家获得其他玩家施放的指定增益时显示正常彩色图标、剩余持续时间和至少 2 层的层数；增益消失后隐藏。自己、自身宠物及载具的施放来源不会触发，来源无法确认时不会按其他玩家处理；其他玩家控制的宠物增益可以计入。

## 控制面板

保留启动模块、缩放、无目标时隐藏、排列方向、配置分享、添加／删除和拖拽排序，并加入预览、解锁移动。默认居中排列，默认移动区域中心 `(0, -120)`；基准图标 40×40，与玩家技能监控一致。没有监控类型、快捷键及颜色选择。

每条监控只有主输入框，灰色占位文字为“输入队友给你的技能名或ID”，按当前客户端的增益名称或增益法术 ID 匹配。复用跨职业 Buff 名称解析，遇到施法技能与实际增益 ID 不同的情况，请填写实际增益名称或 ID。

输入框下方为“播放声音”，默认不勾选。勾选后显示与“玩家其他监控”一致的音效列表、试听按钮；支持游戏音效、已注册共享媒体、自定义文件路径或音效 ID，使用主声道。

## 声音触发

每次新获得已配置增益时播放一次，不因倒计时刷新而重复。可读取独立实例 ID 时按新实例判断；旧接口按增益与施放来源判断，持续刷新已有增益不重复提示。登录时已经存在的增益、设置预览及设置窗口打开时不自动播放；“试听”按钮仍可主动播放。

正式服和使用受保护光环的客户端由原生容器过滤他人施放来源、绘制图标与倒计时。声音仅在来源和增益获得状态可以公开读取时播放，不能从受保护的显示状态推断播放时机。原生显示保留各监控槽位；普通接口会紧凑排列当前生效项目。

## 保存与分享

监控内容和音效设置由所有职业共用，切换角色职业时不切换列表。配置分享只有“导出配置”“导入配置”两个按钮。“其他”中的整体配置分享也包含本模块的通用配置与布局。

升级时将此前最后显示的监控列表保留为通用配置，旧职业表保留在本地供恢复，不再参与切换。仍支持导入旧职业分享字符串；旧全职业字符串优先取当前职业，若无对应职业则取职业标识排序后的首项，作为通用列表。

动态显示和公开数据的声音提示可在战斗中更新；控制面板沿用战斗中不可修改布局的限制。名称或原生过滤重新绑定延后至脱战。
