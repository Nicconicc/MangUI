# 玩家常驻团队增益监控

位于“常用物品监控”上方，监控玩家自身缺少的团队增益。只显示缺少的 Buff；获得增益后隐藏图标，增益消失后重新显示。来源可以是自己、队友或其他玩家。

支持启动模块、缩放、无目标时隐藏、排列方向、预览和解锁移动。图标基准尺寸 40×40，默认排列居中，默认移动区域中心为 `(0, -400)`。

“仅团队时显示”在“无目标时隐藏”右侧，默认勾选，按加入团队判断，并不要求已经进入团队副本。取消勾选后可在其他场景显示；与“无目标时隐藏”同时启用时，两项条件都需满足。设置面板预览不受这两项条件限制。

## 配置分组

- **通用Buff设置**：同一客户端内账号角色共用。
- **职业Buff设置**：按职业保存，同职业角色共享。

每组默认一个空行，支持添加、删除和拖拽排序。每条监控提供“常驻Buff”“职业武器强化”“消耗品武器强化”类型。旧配置自动按“常驻Buff”处理，不改变已有内容。

常驻 Buff 包含图标、两个横向 Buff 名称或 ID 输入框，以及删除按钮；两输入框中间标注“或”，只要任意一个 Buff 存在，该条图标就隐藏；两者都不存在时显示一个图标。允许只填写其中一个输入框，两个都为空时不生成监控图标。旧配置保留为左侧输入，右侧为空。占位文字为“输入Buff名称或ID”。名称按当前客户端识别，ID 按对应 Buff 的法术 ID 匹配。默认显示左侧 Buff 图标；左侧未填写或无法解析图标时使用右侧图标，均无法解析时显示问号。

名称识别独立于当前职业法术书：常用团队增益通过客户端法术数据建立跨职业索引；实际获得过的 Buff 名称、图标及同名等级 ID 会按客户端版本和语言缓存。其他未识别的名称在此设置页打开且脱战时分帧查找，找到后自动更新图标；可直接填写 ID。按名称监控兼容已识别的同名等级，按 ID 则保持精确匹配。

缺少的 Buff 图标正常彩色、完全不透明，不提供物品使用或制造点击动作。由于只显示未获得的 Buff，不显示持续时间和堆叠数。普通客户端会将缺失项目紧凑排列；使用原生受限光环接口的客户端将两输入的 Buff ID 集合交给游戏判断，由游戏控制图标隐藏，保留各监控位置以避免读取受保护的光环状态。

“其他”中的全局配置分享包含本模块的通用列表、全部职业列表和显示设置。旧配置缺少本模块时自动补入默认值。新增模块不改动物品监控数据。

## 武器强化缺失提醒

- **职业武器强化**：盗贼、萨满、术士、圣骑士可选择自动推荐或当前已学会的强化。按版本与已学技能限制选项；不包含死亡骑士符文熔铸。经典盗贼分别检查武器，MoP 及之后的毒药按玩家自身增益检查。探索赛季自动规则兼容致命酝酿。术士涂层仅在 WLK 与无限服启用；TBC 装备型石头不会错误提醒。
- **消耗品武器强化**：输入物品名称、物品 ID、物品链接，或将背包物品拖入输入框／图标。也可输入部分名称后点击“选择”，在当前版本的物品列表中筛选。识别后显示物品图标和名称。未收录的物品提示“暂不支持此物品，请从列表选择”，不会生成错误提醒。列表内同一产品的各品质均视为满足该产品。
- **检查位置**：主手、副手、主副手、任一武器。主副手分别生成缺失图标；任一武器只要求一把适用武器满足。未装备武器、盾牌、非武器副手、未学会的职业强化和等级不足的物品不会生成提醒。磨刀石、平衡石及远程强化还检查武器类型。
- **显示**：只显示缺失项，补上后隐藏；战斗中、脱战、换装备及强化过期后都会刷新。共用模块缩放、方向、团队与目标显示条件、预览和解锁移动。图标标注主手／副手，英文为 MH／OH，悬浮显示物品或技能详情及缺失位置，不提供自动使用或施法。
- **识别**：优先读取临时武器强化的具体附魔 ID，兼容旧接口与 `C_PaperDollInfo.GetTemporaryEnchantmentInfo`。不使用触发后的短时增益，也不读取物品链接中的永久附魔 ID。对自定义客户端不同 ID 或叠加效果，补充检查武器详情中的对应强化名称；不可读取的受保护状态不推断为缺失。时光服不套用原版 WLK 的旧物品等级限制。

录入示例：选择“消耗品武器强化”，输入 `34539`（正义武器涂层），检查位置选择“主手”。数据随已有通用／职业配置保存和分享，无需用户查找附魔 ID。
