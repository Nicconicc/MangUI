# 正式服玩家资源

正式服“玩家与目标主框体 → 玩家资源”使用用户提供的《正式服玩家资源点.txt》WeakAuras 导出。原导出包含184个节点：14个组、120层贴图、48层模型、2层文字。全部170个可见层均已转换为声明式数据，不执行导出中的脚本。

|---|---|---|
|潜行者三专精、德鲁伊四专精|7个连击点位置|玩家连击点，资源类型4|
|冰霜法师|5个冰刺与层数文字|玩家“冰刺”光环，正式服法术205473|

|鲜血／冰霜／邪恶死亡骑士|6个可用符文，三套不同外观|GetRuneCooldown返回的可用符文数量|

以上数量、排序、模型编号、模型镜头、序列、贴图颜色与旋转、相对位置及条件均来自原稿。保留原稿的潜行者第七点左置、符文数量判断及术士第五点的等于条件。原稿转换未增加额外点位；716版另按用户要求增加复仇灵魂残片。导出保存的 tocversion 不作为加载条件，模块仅由当前客户端的正式服项目标识启用。

原稿的屏幕绝对位置由 MangUI 已有“玩家资源”的位置代替。各套原稿以资源贴图中心归一化后，保留相对位置及1.2倍组缩放。继续支持X／Y偏移、缩放、资源间距、预览及配置分享。正式服切换目标不清空玩家连击点；无目标的整体显示仍跟随现有设置。

自702起，在上述原稿几何基础上，以旧版同一张`Frame_Bar`白色菱形边线校准显示尺寸：主菱形由36放大至50，整套图层、模型与布局同步放大约38.9%。死亡骑士另保留旧符文的`1/.9`补偿，主菱形为约55.56。原稿大小点之间的比例保持一致。移动边界和预览按放大后的范围计算，额外资源间距仍以设置值计算。

自703起，正式服潜行者按专精使用点数上限：奇袭（259）与敏锐（261）为7，狂徒（260）为5。预览、可见图层及移动范围同步采用该上限；实际点数继续直接读取玩家连击点。暗影牧师的狂乱值（13）和元素萨满的漩涡能量（11）隐藏玩家左侧独立能量数值，保留右侧显示；切回法力后恢复原规则。

可读取的资源值保留原稿0.25秒缩放／淡入淡出动画。正式服返回受限资源值时，将值直接交给原生阶梯曲线与透明度接口处理显隐、萨满变色和透明度，不在Lua中比较、运算或推测受限值；这种情况下不执行依赖前后值比较的进出动画。数值文字直接传入原生文字接口。缺少相关客户端API时不显示无法判定的点。

程序对照已覆盖170层的来源、几何、阈值、模型和条件，以及资源／光环／符文事件、专精切换、预览、移动模式模型恢复、旧配置及配置分享。模型粒子、客户端实际着色和受限值原生渲染仍需在游戏内确认。

实现：`RetailResourceData.lua`保存原稿数据，`RetailResources.lua`负责正式服状态和绘制。经典版本继续使用原有`Resources.lua`及`MistsResources.lua`分支。

## 复仇灵魂残片（716）

恶魔猎手复仇专精581的玩家资源读取自身灵魂残片Buff 203981（不依赖本地化名称）。跟随Buff实际层数，而不是累计拾取、击杀或技能次数。走近吸收及灵魂裂劈／幽魂炸弹消耗都会降低可用点数；移除Buff归零。资源上限使用C_Spell.GetSpellMaxCumulativeAuraApplications(203981)，支持5／6点；元数据不可用时回退5点。主能量条仍显示恶魔之怒，噬灭专精1480的第三资源条保持原逻辑。

每点含背景模型4533205、原有Frame_Bar.blp白线、原创VengeanceSoul.tga紫色／青色灵魂图案和上层模型1355191，复用潜行者的主／小点比例、分层、模型镜头及0.25秒动画。透明图案由矢量形状抗锯齿生成，不替换共享贴图。

支持CustomAuraContainerTemplate的客户端使用6个原生光环槽位，全部只匹配玩家203981。每个槽位只创建一个按钮并绑定一个原生ApplicationBar，minApplications分别为1～6；其后代包含该点全部图层，游戏直接控制达到门槛时的显隐。Lua不查询绑定条值、光环身份、文字或显隐，也不利用受限值计算曲线。原生模式不推断获得／消耗时机，沿用持续的模型特效。旧版无此接口时查询自身Buff的可读层数；无法读取时安全隐藏。

### 717：真实数量与原生图层隔离

普通绘制不再以最大容量作为当前数量。GetPlayerAuraBySpellID(203981)可读取时，按实际applications显示，返回nil则为0；返回受限对象／层数或查询失败时不比较、不计算该值。准备完整的六个原生槽位后，才在受限状态启用独立的原生点；普通点全部隐藏，原生点始终是绑定条的后代。绑定未完成／失败不显示满点。初始化异常会报告“灵魂残片原生绑定”，不再将半完成状态视为成功。

原生光环筛选单位固定为player，HELPFUL过滤仅含203981，不依赖系统资源光环的施法者标志。每个原生点直接在初始化回调里创建，原普通图层不再重设父框体。可读／受限切换时只显示其中一套；不会读取绑定对象的值、光环身份或显隐来重建状态。

灵魂图案、背景模型与前景模型的宽高统一乘1.2。白线Frame_Bar.blp的宽高不变，不整体放大资源容器；间距和图层中心偏移不变。
