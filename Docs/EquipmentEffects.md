# 玩家其他监控

位于“玩家技能监控”下方。监控列表按职业保存，同职业角色共享；普通 Buff／Debuff 和“装备触发”条目都随职业配置切换。缩放、位置、排列方向、无目标时隐藏和底部“装备监控补充”也不随职业切换。

## 监控条件

- 玩家 Buff 已找到／未找到：匹配玩家身上的增益，按存在／缺失条件显示。
- 目标 Debuff 已找到／未找到：仅匹配玩家自己施放的减益；无目标时两种都不显示。
- 已找到时显示持续时间；未找到时不显示倒计时。发光随显示条件，声音只在条件从未满足变为满足时播放一次。
- “监控设置”中的“监控类型”恢复五选一：玩家 Buff 已找到、玩家 Buff 未找到、目标 Debuff 已找到、目标 Debuff 未找到、装备触发。选择“装备触发”后，在右侧选择装备部位，下方自动显示当前装备名和图标；装备条目与其他条目统一添加、删除和拖拽排序，并自动跟随换装。不再显示独立的“装备监控设置”分组。
- 未装备物品，或装备没有可识别的触发／使用效果时，不显示游戏内监控图标。已识别效果的装备在 Buff 尚未激活时仍显示，沿用激活／冷却样式；发光和声音只跟随效果激活。
- 从曾使用共用装备列表的版本升级时，将其一次性并入原活动职业，按部位避免与该职业已有装备条目重复，保留原活动条目的设置；其他职业不继承这份旧列表。未迁移到共用列表的历史职业装备条目继续保留。

## 装备效果与冷却

`Code/Modules/Cooldowns/EquipmentData.lua` 保存用户提供的装备、附魔和宝石效果对应数据，并区分所提供的时光服专属数据。占位 Spell ID 已剔除；未知内置冷却不套用 45 秒默认值。

武器附魔不依赖宝石字段：没有插槽或宝石字段为空的装备链接也会独立读取附魔 ID。补充“斩杀”的附魔 ID `3225` → Buff Spell ID `42976`，没有固定内置冷却；对应关系见 [WoWSims 的斩杀实现](https://github.com/wowsims/wotlk/blob/master/sim/common/tbc/enchant_effects.go#L137)。

装备图标上方优先显示激活 Buff 的剩余时间，随后显示可获取的装备冷却或已知内置冷却的剩余时间。内置冷却从触发时开始计时，Buff 消失时不会重新起算。正在计时的已知内置冷却会记录到本地，重载后恢复；计时记录不参与配置分享。

换装、卸下再装备、饰品互换位置也会记录装备锁定：被动效果采用对应表或手动补充中的已知内置 CD（例如剑刃刺绣 60 秒），主动装备采用换装后的 30 秒锁定；游戏接口有实际冷却时优先使用实际值。换装锁定与效果触发的内置 CD 分开记录，并保留其中尚未结束的较长计时。未知被动 CD 和明确无固定 CD 的被动附魔不会套用默认秒数。

饰品计时按角色和装备 ID 保存，在两个饰品栏之间移动仍保留；旧版按位置保存的计时会迁移。模块关闭期间也跟踪换装，登录、重建预览、延迟加载装备名称以及重复的背包事件不会重新开始计时。装备栏、旧版物品和新版物品冷却接口共同补齐公开冷却。相同装备 ID 的两份饰品在没有独立物品实例标识的记录中共用计时。

主动使用和被动触发的装备，在效果激活期间都保持正常彩色、不透明，优先显示 Buff 倒计时。效果结束后，若固定冷却尚未结束，图标才褪色且透明度为 50%，倒计时保持不透明。没有固定冷却的效果保持正常图标，只显示激活效果的持续时间。

手动补充按装备 ID 覆盖内置记录，包括该装备的附魔／宝石映射。每行依次填写装备 ID、实际 Buff Spell ID、内置冷却秒数；多个 Buff ID 可用逗号分隔。冷却填写 `0` 表示没有固定内置冷却，留空表示未知。相同装备 ID 有多行时，以最后一行为准。仅填写装备 ID、尚未填写 Buff ID 时，也会停用该装备的内置映射。

### 双持相同附魔

在时光服等可读取光环数据的客户端，若两个武器监控使用相同的效果 Spell ID（例如双狂暴），会保留两个显示位置，按独立 Buff 实例分配倒计时、发光和声音条件。已分配的实例保持原位置；其中一个消失时，另一个不会移到空位。API 光环顺序变化和模块重新应用不会把两条倒计时合并。武器图标仍显示所选位置的装备，位置不表示实际触发的是主手或副手。

优先使用有效且不重复的 `auraInstanceID` 跟踪；API 返回零、重复 ID 或没有实例 ID 时，使用持续时间信息维持显示位置，无法完全区分同一时刻发生的刷新和替换。扫描时独立保存每条光环数据，避免兼容接口复用结果表导致覆盖。受保护、不可读取的光环继续使用原生显示接口，不以猜测确定武器来源或独立实例。

## 音效与分享

声音使用 Master 主声道，可选内置提示音、声音套件 ID、自定义文件路径以及通过共享媒体库注册的声音资源。共享媒体可来自任意已加载插件，不依赖某个特定插件。

“导出当前职业配置”包含该职业的全部五类监控条目；导入时不修改其他职业或装备补充表。“导出全职业配置”包含各职业的完整列表及装备补充表。全局配置分享也包含本模块设置。旧版带独立装备列表的全职业字符串仍可导入，独立列表一次性合入当前活动职业。导入字符串仅作为数据读取，不执行代码。

## 客户端限制

支持原生光环容器的客户端通过游戏原生显示接口处理受保护的光环、持续时间和层数。若客户端禁止插件读取某个光环的存在状态，插件不会据此触发声音，也不会猜测该次触发的隐藏内置冷却；原生光环图标、倒计时和发光仍由游戏显示。装备公开冷却和已保存的已知计时可继续使用。

同一装备的使用技能 ID 不一定等于实际 Buff ID。未收录或服务器改动过的装备需要核对实际效果，并通过“装备监控补充”修正。已知内置冷却需至少观察到一次触发，无法在首次载入时推断更早发生且已经消失的 Buff。
